# 局部遮罩清理规范

用于分割后的地面残留、背景碎片、浅色漏抠或分区接缝。复用诊断方法和操作约束；坐标、颜色、阈值及保护对象都由当前素材决定。简单色键或已合格的分割结果不必增加这一层。

## 先确定错误来源

对照原图、基础 alpha 和深浅背景合成图，区分误保留背景、误删主体、颜色溢出及原视频自身缺陷。先改最直接的一处：区域或模型选择、局部遮罩规则、最后才是细小碎片处理。每加一项操作，先在相同代表帧上比较，确认没有用主体缺损换取背景干净。

保留原 RGB 和基础遮罩。一般清理只改 alpha；去溢色会改变 RGB，须单独记录，不能与“删掉绿色像素”混为一谈。遮挡、变形和运动模糊不是遮罩碎片，清理不能恢复它们。

## 把规则写成素材配方

每条规则至少记录以下内容，可使用任务配置或处理脚本，不要求新增一套配置语言：

| 内容 | 要说明的决定 |
|---|---|
| 依据 | 哪些源帧、哪个部位出现什么错误 |
| 范围 | 适用源时间/动作、源坐标区域、颜色或置信度条件 |
| 操作 | 预测、保留、剔除、覆盖、开闭运算或填孔 |
| 保护 | 哪些主体、同色部位、细线或真实空隙不能受影响 |
| 合并顺序 | 重叠区域使用最大值、局部替换或其他明确方式 |
| 参数与版本 | 实际阈值、像素单位、模型及脚本/配方版本 |
| 验证 | 清理前后样张、全片复查结果、已知损伤及是否撤销 |

不同分辨率复用配方时，按本片尺寸换算区域和核大小，并重新看样张。可在配方中记录归一化坐标，运行前换成真实源像素；现有 CLI 的 `box` 仍接收源像素坐标。面积阈值应考虑分辨率平方变化，不能沿用上一片的固定像素数。

## 区分预测区域与应用区域

预测裁剪保留足够上下文；实际修改的区域可以更小。例如，用较大的腿脚区域预测靴子，只把结果写回确认需要修正的下方区域。不要因为局部预测放大了某个物体，就覆盖整块裁剪中的原有好遮罩。

多个主体通常需要取最大值合并，避免丢掉小动物或道具；纠正误抠有时需要局部替换。最大值合并不会删除旧遮罩中的背景。替换时复查边界是否出现直线切口、透明度突变或白色矩形，必要时扩大上下文或在可靠重叠区过渡。不能用模糊边缘掩盖错误轮廓。

当前 `video_sprites.py` 的 `regions` 只有最大值合并，预测区域与写回区域相同。单独写回、局部替换和保护区域需要额外处理代码，不能把本文的概念字段当成现有参数。

## 按条件选择操作

| 操作 | 可采用的条件 | 需要检查的损伤 |
|---|---|---|
| 局部颜色剔除 | 颜色确属背景，且已限定区域内没有应保留的同色主体 | 绿衣、白鞋、金属反光、半透明边缘被删 |
| 地面约束 | 本片可辨认地面范围与外观，动作全程没有需要保留的同类部位进入 | 低垂衣摆、亮色鞋底、触地特效丢失 |
| 小连通块清理 | 已确认是低置信度的背景孤岛，大小与时序证据相符 | 手提包、颗粒特效、胡须、断开的武器被删 |
| 开运算或收缩 | 可明确定位细小背景连接，主体细节有余量 | 鞋尖、鞋跟、包带和手指被吃掉 |
| 闭运算或填孔 | 某个实体部位被误抠出孔，作用范围明确 | 腿间、手臂间、包带内的真实空隙被填平 |

颜色或大小相同不等于语义相同。背景与主体无法可靠区分时，关闭该规则，改用更合适的分割方法、局部人工遮罩或报告限制。持续存在的小物体不能只因面积小就删除；短暂出现也可能是合法粒子，仍需对照原图。

形态学操作应记录核大小和锚点，检查轮廓是否被平移。填孔限于确认的实体局部，不能对整个人物或多主体组合默认执行。

## 用同一配方检查整个动作

在相同源坐标系中应用规则，保留固定画布、缩放和锚点。规则随时间切换时记录适用区间，检查切换帧；确需跟踪的区域另行实现跟踪与坐标映射。不要逐帧随意改阈值来追求单张好看，否则容易产生闪烁。

代表帧包含起止、最大伸展、交叉遮挡及易误抠的浅色/细线部位。跑完全片后查看所有导出姿态，再检查异常帧及其相邻帧；前几张合格不能代表后段合格。

可用主体面积、包围盒、相邻 alpha 差和被剔除面积定位突变，但不能据此自动删除帧或判定质量。真实动作也会突变。最终在深色、白色背景上按原速与慢速播放，必要时逐帧对照；棋盘格可能掩盖灰白残留。循环另查最后几帧接回开头的姿态、运动方向与速度。

## 保留复现与撤销依据

中间目录保留基础遮罩、清理配置、处理顺序及清理前后样张。缓存标识应包含源文件身份、模型/遮罩配置、额外清理配置和脚本版本；这些内容变化时重算遮罩。原始 CLI 只根据源文件身份和 `mask` 配置区分遮罩缓存，额外脚本必须扩展标识或使用新的缓存目录，不能假定它会识别外部规则变化。

交付分别说明：文件与时序检查是否通过、是否做过视觉复查、抠图是否达到所需质量、循环是否验收通过。PNG 有透明通道、Canvas 非空或播放正常，都不能替代质量验收。报告局部残留及主体损伤，用了额外脚本就说明它与原始 CLI 的边界。

本次黑衣人物片段中的绿色差值、脚部灰色阈值、上下分区高度、连通块面积及核大小仅是该素材的参数，不设为其他视频的默认值。
