# 抠图路线

纯色使用 `mode=chroma`，显式 RGB key、threshold 和 softness。检查衣服/特效是否同色。当前 RGB 距离色键有软边；绿/紫边可显式开启 `despill`，见 [config.md](config.md)。去溢色改动 RGB，默认只作用于透明边界附近及半透明像素，采用上游的色键通道上限方法，不向其他颜色混合。深浅背景复查；半透明同色衣服、发光特效也可能受影响。默认关闭；不对模型分割或任意颜色自动启用。

纹理/渐变背景使用 `mode=model`，额外依赖 `rembg` 和 ONNX 运行时。优先复用已有环境与模型；首次可能联网下载。模型文件放工作目录，不放技能目录。先用代表帧做小样。

浅色小动物可能被模型当背景。**只取模型遮罩，RGB 使用原视频**，避免对已预乘透明的黑色像素填孔。

`regions` 可分区处理人物、狗、道具并放回原坐标合并。各区域的 box、threshold、close、fill_holes、largest 都是素材级设置：

- box 应覆盖全动作范围，固定区域不是跟踪器。
- largest 只适用于明确限定为单个主体的区域，整图默认保留所有区域。
- fill_holes 仅用于实体被误抠空的封闭轮廓，也可能填掉手臂等真实空隙。
- close 会连接断线，也会粘连肢体；保守增加。
- inset 会吃掉细绳、胡须、毛发，默认 0；纸边与真实白描边要区分。

不能还原被遮挡部分，也不自动修复变形、模糊和透视。不能可靠分离时说明限制。

深/浅背景对照原图检查轮廓、空隙和道具。数值只定位问题。原 `h3-game-sprites` 的 bg_purity 由互补二值掩码相加得出，基本恒为 1，不能据此宣称干净。

局部调参后仍有地面、背景碎片、浅色漏抠或区域接缝时，读取 [mask-refinement.md](mask-refinement.md)。它规定如何选择和验证清理操作，不代表原始 CLI 已实现新的过滤字段。现有 `regions` 在重叠区域取 alpha 最大值，不能用于覆盖纠正另一区域的误抠。
